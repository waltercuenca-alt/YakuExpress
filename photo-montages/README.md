# Montajes Premium

Esta carpeta recibira fondos y overlays para Montajes Premium.

No colocar fotos privadas de clientes en esta carpeta.

Fondos esperados:
- backgrounds/ola-gigante.jpg
- backgrounds/delfines.jpg
- backgrounds/atardecer-marino.jpg

Overlays esperados:
- overlays/splash-frame.png
- overlays/yakupark-premium-frame.png

Si esos archivos no existen o no cargan, YakuExpress usa fallback canvas.

Medida recomendada:
- Fondos JPG: 1080x1350 px
- Overlays PNG transparentes: 1080x1350 px

## Recomendaciones de rendimiento

- Usar JPG para fondos.
- Usar fondos de 1080x1350 px.
- Peso ideal por fondo: menor a 1 MB.
- Peso maximo recomendado por fondo: 2 MB.
- Evitar PNG pesados para fondos.
- Usar PNG solo para overlays transparentes.
